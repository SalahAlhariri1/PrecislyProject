# brief.dev

**A Sales Intelligence tool for Sales Engineers.** Enter any company name and get an instant pre-call brief: live stock data, recent news with sentiment analysis, and Claude-generated talking points tailored to your pitch.

Built with Next.js, Claude API, Alpha Vantage, and NewsAPI.

---

## Features

- **Live stock data** — real-time price, change, sparkline via Alpha Vantage
- **Recent news** — last 30 days of headlines with sentiment badges via NewsAPI
- **AI talking points** — 3 SE-focused insights generated by Claude Sonnet
- **Company snapshot** — revenue, CEO, founded, market cap compiled by Claude
- **Skeleton loading** — staged card reveal with shimmer animations
- **Private company graceful fallback** — skips stock card with `[ PRIVATE COMPANY ]` badge

## Setup

### 1. Clone and install

```bash
git clone <your-repo-url>
cd PrecislyProject
npm install
```

### 2. Configure environment variables

```bash
cp .env.example .env.local
```

Edit `.env.local` and fill in your API keys:

```env
ANTHROPIC_API_KEY=sk-ant-...
ALPHA_VANTAGE_API_KEY=your_key_here
NEWS_API_KEY=your_key_here
```

**Where to get keys:**
- **Anthropic** → [console.anthropic.com](https://console.anthropic.com)
- **Alpha Vantage** → [alphavantage.co/support/#api-key](https://www.alphavantage.co/support/#api-key) (free)
- **NewsAPI** → [newsapi.org/register](https://newsapi.org/register) (free dev tier)

### 3. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Usage

1. Type a company name (e.g. `Salesforce`, `Stripe`, `NVIDIA`) in the search bar
2. Click **GENERATE** or press Enter
3. Watch the brief assemble in real time — stock → snapshot → news → talking points

## Project Structure

```
/app
  layout.tsx              # Root layout with Geist fonts + metadata
  page.tsx                # Main UI — search, state management, card reveal
  globals.css             # Shimmer/pulse animations, global reset
  /api/brief/route.ts     # POST handler — orchestrates all 3 APIs

/components
  Navbar.tsx              # Top bar with brand + model/live badges
  SearchBox.tsx           # Search input with prefix + generate button
  CompanyHeader.tsx       # Company name, tags, fetched time
  StockCard.tsx           # Price, change %, sparkline bars
  SnapshotCard.tsx        # Revenue, CEO, market cap stat rows
  NewsCard.tsx            # Headlines with sentiment badges
  TalkingPointsCard.tsx   # Numbered SE talking points from Claude
  SkeletonCard.tsx        # Animated shimmer loading placeholder

/lib
  alphaVantage.ts         # Stock quote + sparkline fetching
  newsApi.ts              # News search + sentiment inference
  claude.ts               # Snapshot + talking points generation
```
